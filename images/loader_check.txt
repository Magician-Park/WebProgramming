2026-10-15 — 공통 페이지 로딩 화면

실제 page-loader.js를 실행한 모의 DOM 검사:
- 문서 진입 표시 → load 완료 → 최소 표시/페이드 → 숨김, main aria-busy 원상 복원.
- 내부 HTML 이동에서 표시하고 브라우저 기본 이동을 preventDefault로 취소하지 않음.
- 같은 문서 앵커·GitHub 외부 링크·새 탭·Ctrl/Command/Shift·중간 버튼·다운로드·이미 취소된 링크는 제외.
- 문서 편집 중 로딩 표시를 우회해 기존 이탈 확인 유지.
- load 미완료 또는 실패한 이동의 4초 복구, 반복 클릭 시 타이머 정리.
- 뒤로/앞으로 캐시 pageshow 복원 시 즉시 해제.
- 동작 줄이기 설정에서 최소 표시/페이드 대기 없음. CSS도 회전/전환 없음.
- loader는 HTML에서 hidden 상태여서 JavaScript 미실행 시 본문을 가리지 않음.

실제 7개 주차 문서 기반 편집 모의 DOM 검사:
- 기존 편집·저장·취소·복원·다운로드 흐름 통과.
- 현재 로딩 표시와 aria-busy가 남아 있어도 다운로드 HTML에서는 hidden 초기 상태·기본 class로 정리.
