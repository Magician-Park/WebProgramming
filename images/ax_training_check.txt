2026-10-17 — AX 교육 사진 추가
중소벤처기업진흥공단 AX 교육 프로그램 제목 옆에 기존과 동일한 초록색 사진 아이콘을 추가했다. 아이콘은 images/ax-training.png를 ax-training-dialog 중앙 팝업으로 연다. 제목과 GitHub 아이콘의 기존 저장소 링크는 유지했다. 사진은 사용자 제공 검정 가림과 표시 픽셀을 그대로 보존하고 PNG 텍스트·EXIF 메타데이터만 제외했다. CSS·공통 dialog 스크립트·학년·시기·역할은 유지했다.
사진 크기 1024×1024; 원본과 픽셀 동일. 사진 아이콘 총 10개·dialog 6개·실적 10행 유지. 각 aria-controls·이미지 경로·ID 고유성·내부 링크를 소스에서 확인했다. 실제 브라우저 배치·클릭·Esc/Tab 검수 및 최신 HTML 외부 W3C 재검사는 미수행. Git 커밋·push·배포 없음.
