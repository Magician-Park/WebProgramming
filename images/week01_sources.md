# 1주차 학습 정리 – 범위와 출처

주자료: 「[웹프로그래밍] Lec01. 오리엔테이션」 PDF의 실제 파일 페이지 4~21쪽(슬라이드 쪽수와 일치). 텍스트 추출과 18쪽의 렌더링을 확인했다. 원본은 수정하지 않았다.

| PDF 쪽 | 페이지에서 정리한 내용 |
|---|---|
| 4~5 | ARPANET, TCP/IP 표준 채택·전환, NSFNET, 웹·브라우저·W3C 연표 |
| 6~9 | CERN의 정보 공유 목적, 하이퍼텍스트, HTML·HTTP·URL, 브라우저 보급, 웹 표준 |
| 10~11 | 2007·2013년 인터넷 분포 자료는 당시 통계라는 설명 |
| 12~15 | 마크업 유래, SGML·HTML·XML·XHTML·HTML5의 흐름, 구조·표현·동작 구분 |
| 16~19 | 클라이언트·서버, 요청·응답, TCP·IP·패킷·HTTP, IPv4·IPv6 |
| 20~21 | 도메인 이름, DNS, URL 구성과 예시 |

PDF 내 연도 차이와 기본 모델의 단순화는 아래 자료로 보완했다. 학습 페이지에서도 해당 내용 가까이에 링크를 표시했다.

- [CERN – The birth of the Web](https://home.cern/science/computing/the-birth-of-the-web/): 웹 제안과 초기 구현.
- [W3C – A Little History of the World Wide Web](https://www.w3.org/History.html): 초기 웹과 표준화의 흐름.
- [Internet Society – TCP/IP migration in 1983](https://www.internetsociety.org/blog/2016/09/final-report-on-tcpip-migration-in-1983/): 1982년 표준 채택과 1983년 전환의 구분. 초기 ARPANET의 NCP를 IP와 혼동하지 않도록 보완.
- [RFC 1866 – HTML 2.0](https://www.rfc-editor.org/info/rfc1866/): 자료 13쪽의 1994년 표기 대신 1995년 11월 발표 시점 적용(15쪽 도표와 일치).
- [WHATWG FAQ](https://whatwg.org/faq): 자료 14쪽의 2006년 대신 공식 설립 연도 2004년 적용.
- [W3C – HTML5 Recommendation](https://www.w3.org/press-releases/2014/html5-rec/): 2014.10.28 발표.
- [RFC 791 – IPv4](https://www.rfc-editor.org/info/rfc791/), [RFC 8200 – IPv6](https://www.rfc-editor.org/info/rfc8200/): 주소 길이와 IP의 역할 확인.

기타 설명: DNS의 일대일 대응과 URL 경로의 실제 파일 대응을 일반화하지 않았다. 주소 예시는 설명용이며 네트워크 요청 실습을 자동 실행하지 않는다. 강의 이미지·원본 PDF는 ZIP에 넣지 않았다. 실제 수업 완료 여부·배포 실습 URL을 대신 검수한 것으로 간주하지 않는다.
